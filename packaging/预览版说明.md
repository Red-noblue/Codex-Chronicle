Codex Chronicle 公开预览版：本地优先的 Codex 对话档案库，采用 MIT 许可证。

支持会话浏览与搜索、主对话和子代理关系、批量影响预览与数字确认、本地 / GitHub 私有仓库归档、归档恢复与副本转换、存储维护，以及亮暗主题和阅读密度。应用使用系统浏览器显示界面，默认自动识别 Codex 目录并保持只读。

### 选择安装包

- **macOS 14+**：`macOS-arm64.dmg` 对应 Apple 芯片，`macOS-amd64.dmg` 对应 Intel。ZIP 是便携载荷。
- **Windows**：选择 `amd64-Setup.exe` 或 `arm64-Setup.exe`；也提供便携 ZIP。
- **Linux**：选择对应架构的 DEB / RPM，或使用 tar.gz / ZIP；ARM64 包面向运行 64 位 Linux 的树莓派等设备。
- `SHA256SUMS` 包含全部安装包的 SHA-256 摘要。

### 验证范围

发布流程在 macOS、Windows、Linux 运行 Go 回归、静态检查与前端构建，再生成六种系统 / 架构组合的安装包。与运行器架构相同的载荷进行隔离启动、版本核对与安全退出验证；Linux DEB/RPM 额外解包，核验完整文件清单、摘要、普通用户读取权限并隔离启动。Windows EXE 的封装和 Linux 解包检查不等于完成所有桌面安装场景测试。

新的候选流程在原生运行器上以仓库固定公钥核验最终 ZIP 并进行隔离启动，再冻结六平台文件与源码提交，生成 GitHub 构建来源证明。公开发布只推广 main 上已成功验收的相同字节，不重新构建或替换公开资产；GitHub Releases 保存版本与安装包，更新通道的暂停和撤回独立维护。

macOS ARM64 在开发设备验证过安装 / 卸载、覆盖更新、失败回退、强杀安装后恢复，及独立更新源的下载、验签、激活、坏候选拒绝、回滚和下载中断后恢复。这些测试未操作真实会话，也不是物理断电实验。此前另有选定真实会话的归档、删除和恢复实验，不代表所有平台与 Codex 版本均支持真实写入。

### 当前限制

- **预览版默认只读**。真实 `.codex` 修改仅适配当前用户 macOS 主目录、已审阅的 daemon `0.166.0 / 0.167.0 / 0.167.2 / 0.169.0` 及匹配的数据库 schema。必须由用户显式开启，再逐次预览和确认；活动 / 已加载会话、未知关联与锁冲突仍阻断。Windows / Linux 尚未开放真实会话删除。
- 更新包使用独立的 Ed25519 更新签名；macOS 应用本身采用临时系统签名，尚未 Developer ID 签名或 Apple 公证；Windows 安装器未代码签名，系统可能提示未知发布者。
- 从 `0.1.0-preview.11` 升级时，请先手动安装 `0.1.0-preview.14` 或更新版本。旧版没有更新签名和在线更新索引，无法直接接入新的验签更新渠道。
- 预览版通过静态更新索引检查新版本，不需要 GitHub 账户或访问令牌；支持单独配置下载代理。
- 新版支持中断续传与字节进度，下载、展开、复制和数据快照前检查空间；安装前与实际重启前复核渠道暂停、撤回及包身份。临时网络或空间问题不永久封禁版本；发布方可独立维护通道策略，暂停或撤回时隐藏下载项，已有旧版计划仍受旧客户端能力限制。发布标签源码的隔离升级测试使用临时测试签名，不等同于全部平台公开安装器的实机验证。
- 默认自动检查、下载、验签和预检，可在设置中关闭或手动更新、配置代理；网页不可见且后台任务空闲 5 分钟后自动重启，不主动打开浏览器。切换前保存项目数据库与设置快照，暂停候选实际启动，失败恢复旧版本与快照并跳过问题版本；提交后不回写旧快照。健康确认 24 小时后自动清理已用安装包、预检副本与旧版本，不长期保留历史安装包，不清理外部离线包，文件占用时重试；截止时间跨重启保留，关闭自动更新不影响清理。观察期后不再提供旧版本一键回退。`preview.14` 的旧界面首次升级到此实现时仍需手动退出后台再打开。卸载保留用户数据、归档和恢复材料。
- 本地与云端归档、恢复、加密及网络代理需要相应配置。云端归档默认不上传，只有用户连接账户并主动选择后执行。
- 保留规则尚未开放无人值守自动删除；中断的删除任务需人工复核，不自动续删。

安装、配置及源码构建说明见仓库中文 README。反馈请脱敏，不要附带认证文件、会话正文、数据库或恢复包。
